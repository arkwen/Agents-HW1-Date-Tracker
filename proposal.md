# Proposal: Романтический путеводитель по Москве

## Цель

Создать автономное локально запускаемое веб-приложение для пары, позволяющее вести общий каталог интересных мест Москвы, планировать совместные посещения и сохранять воспоминания о проведённом вместе времени.

Приложение должно объединять интерактивную карту, каталог карточек мест и трекер совместных приключений.

Основной акцент — удобство использования, визуальная привлекательность и надёжное локальное хранение данных.

## Основные возможности

1. Интерактивная карта Москвы на основе OpenStreetMap с маркерами сохранённых мест.
2. Каталог мест в виде карточек с переключением между всеми местами, планами и посещёнными местами.
3. Добавление, редактирование и удаление мест.
4. Перемещение карточек между списками посредством Drag & Drop.
5. Сохранение фотографий, впечатлений, даты посещения и оценки.
6. Статистика совместных приключений и прогресс посещений.
7. Создание пользовательских категорий.
8. Локальное сохранение данных и резервное копирование.

## Границы проекта

### Входит в объём работ

- Основной файл приложения `index.html`.
- CSS и JavaScript непосредственно внутри HTML-файла.
- Использование локально подключаемых библиотек без CDN и API-ключей.
- OpenStreetMap в качестве картографической подложки.
- Загрузка картографических тайлов через интернет.
- IndexedDB для хранения мест и фотографий.
- Экспорт и импорт полной резервной копии.
- Адаптивный интерфейс для экранов от 390 px.
- Начальный каталог с несколькими реальными местами Москвы.

### Не входит в объём работ

- Серверная инфраструктура и backend.
- Облачная синхронизация между устройствами.
- Авторизация и управление пользователями.
- Офлайн-загрузка картографических тайлов.
- Массовое скачивание публичных тайлов OpenStreetMap.
- Полный справочник заведений и достопримечательностей Москвы.
- Необязательные дополнительные функции, перечисленные в исходных требованиях.

## Критерии успеха

- Все основные действия доступны через понятный интерфейс.
- Карта и каталог используют единый источник данных.
- Изменения сохраняются локально и восстанавливаются после перезапуска.
- Статистика всегда соответствует фактическому состоянию каталога.
- Недоступность картографической подложки не препятствует работе с каталогом.
- Приложение корректно работает на мобильных устройствах.
