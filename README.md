# ДЗ №1 · Мини-трекер мест (Вариант A)

Репозиторий для домашнего задания по курсу «Создание ИИ-агентов с нуля» (ФКН НИУ ВШЭ).
Сравнение двух подходов к генерации HTML-приложения одной и той же моделью:
**прямой короткий промпт** vs **разработка по предварительной спецификации**.

## 🎯 Задача

Исходная постановка - мини-трекер учебных задач. Я адаптировал её под личный кейс:
**трекер мест для свиданий в Москве** - чтобы видеть на карте все места, где уже были,
вспоминать впечатления и смотреть фотографии.

## 📁 Структура репозитория

| Файл | Назначение |
|------|------------|
| `date_tracker_v1.html` | Версия 1 — по короткому прямому промпту |
| `date_tracker_v2.html` | Версия 2 — по согласованной спецификации |
| `proposal.md` | Цель и границы (OpenSpec, шаг 2) |
| `spec.md` | MUST-требования и сценарии WHEN/THEN |
| `design.md` | Данные, расчёты, валидация |
| `tasks.md` | Чек-лист реализации и проверок |
| `prompts.txt` | Все запросы к модели и уточнения |
| `report.pdf` | Итоговый отчёт с таблицей T1–T5 и выводом |

## 🚀 Как запустить

1. Скачайте `date_tracker_v1.html` и `date_tracker_v2.html`
2. Откройте любой из файлов двойным кликом - он запустится в браузере (для запуска требуется подключение к интернету, вероятно, с VPN)

Подробные результаты — в `report.pdf`.
